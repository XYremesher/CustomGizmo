# Water Test placeholder assets

`terrain.glb` and `rocks.glb` are borrowed from the tympanus/codrops
"Creating Stylized Water Effects with React Three Fiber" tutorial repo:
https://github.com/thaslle/stylized-water (MIT licensed).

Placeholder land for the Water Test level (`buildWaterTestLevel()` in
game_js.js) until the hand-modeled Blender land piece replaces it - the
water/foam shader logic doesn't depend on which land model is used.
